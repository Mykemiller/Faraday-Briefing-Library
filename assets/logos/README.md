# assets/logos

Approved third-party logos live here, one file per source, named `<source_id>.svg` or `<source_id>.png`
(`source_id` = the `entity_id` in `docs/briefs/entity-universe.csv`).

**This directory is intentionally empty after BL-11 (FDY-177).** No source reached `approved` status in
`docs/assets/logo-register.csv`, so no logo was downloaded. See `docs/assets/README.md` for why.

A logo may be added here only after its row in `logo-register.csv` is `approved`, with the exact URL of
the owner's own terms permitting reuse in a publication recorded in `terms_url`.
